Como Funciona

A plataforma IoT Resource Monitor permite-lhe acompanhar todos os seus dispositivos num único painel de controlo. Cada recurso (sensor ou atuador) é armazenado como uma pasta com ficheiros de texto simples, garantindo simplicidade e transparência.

  • Registo automático de leituras
  • Histórico completo com timestamps
  • API RESTful para integração
  • Autenticação segura com bcrypt
  • Interface responsiva e moderna
